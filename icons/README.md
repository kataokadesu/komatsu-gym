# icons（ロゴとアイコンの置き場）

引継ぎ用に、先行店舗のロゴは入れていません。
ジム様の画像を、下の**ファイル名のまま**ここに置いてください。

## ホーム画面用のアイコン

会員がスマホのホーム画面に追加したときに使われます。

| ファイル名 | サイズ | 用途 |
|---|---|---|
| `icon-192.png` | 192×192 | Android のホーム画面 |
| `icon-512.png` | 512×512 | 起動時の表示 |
| `icon-maskable-512.png` | 512×512 | Android で丸く切り抜かれる用。周囲に余白を多めに取る |
| `apple-touch-icon.png` | 180×180 | iPhone のホーム画面 |
| `favicon-32.png` | 32×32 | ブラウザのタブ |

**ファイル名は変えないでください。** `manifest.json` と `index.html` が名前で探しています。

これらは**背景を塗りつぶして**ください（透明だと、機種によって黒く出ます）。
背景色は `config.js` の `theme.paper` に合わせると自然です。

## アプリの中で使うロゴ

ヘッダー・ログイン画面・チケット券面の3か所で使われます。
`config.js` にファイル名を書いて有効になります。

| ファイル名の例 | 用途 | config.js |
|---|---|---|
| `logo-mark.png` | 明るい背景で使う濃い色のロゴ | `logoBlack` |
| `logo-mark-white.png` | 濃い背景で使う白抜きのロゴ | `logoWhite` |

こちらは**背景を透明**にしてください。チケット券面は濃い色なので、
白い背景のままだと四角く浮いて見えます。

白抜き版が無い場合は `logoWhite` を空にすると濃い色のロゴが使われますが、
券面では見えにくくなります。

## 画像を置かない場合

`config.js` の `logoBlack` / `logoWhite` を空のままにすると、
店名の頭文字を入れた円形マークを自動で作ります。そのままでも使えます。

ホーム画面用のアイコンを置かない場合は、スマホの既定のアイコンになります。
機能には影響しません。

## 作り方のメモ

ロゴの元画像（jpg など）から上のサイズを作るときは、
画像編集アプリの「書き出し」でサイズを指定するだけです。
元画像も `logo-source.jpg` などの名前でここに置いておくと、作り直すときに楽です。

# stores（店舗写真の置き場）

2店舗以上あるジムで、店舗の写真を出す場合に使います。
1店舗だけなら、このフォルダは空のままで構いません。

## 使い方

1. 店舗ごとの写真をここに置く（例: `store-honten.jpg`）
2. `config.js` の `stores` にファイル名を書く

```js
stores: [
  { id:"s1", name:"本店",   address:"大阪府〇〇市…", map:"https://maps.app.goo.gl/xxxx", photo:"stores/store-honten.jpg" },
  { id:"s2", name:"〇〇店", address:"",               map:"",                            photo:"stores/store-02.jpg" },
],
```

| 項目 | 内容 |
|---|---|
| `id` | 中で使う印。**あとから変えないでください**（予約や会員に保存されます） |
| `name` | 画面に出す店舗名 |
| `address` | 住所。予約完了やマイページに出ます |
| `map` | Google マップのリンク |
| `photo` | 写真のファイル名。空なら写真は出ません |

## 写真のサイズ

横幅 1200px くらい、1枚 300KB 以下にしてください。
大きすぎると、スマホの電波が弱いところで表示が遅くなります。

## 注意

`stores` を2つ以上書くと、**予約枠・トレーナー・会員が店舗ごとに分かれます。**
1店舗のジムで誤って2つ書くと、会員が店舗を選ぶ画面が出てしまいます。
1店舗なら `stores: []` のままにしてください。

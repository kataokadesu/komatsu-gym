# 予約のお知らせメール（お店の Gmail から送る）

お店の Gmail からそのまま送ります。**ドメインも費用も要りません。**
Google アカウントの機能（Apps Script）を使うので、追加のサービスに登録する必要もありません。

| | |
| --- | --- |
| 差出人 | `〇〇ジム <お店の Gmail アドレス>`（名前は店名、アドレスは Gmail） |
| 送れる数 | 1日 100通まで（無料の Google アカウントの上限） |
| 費用 | 0円 |
| 返信 | お客様が返信すると、その Gmail に届きます |

## 送るメール

| いつ | だれに |
| --- | --- |
| 予約したとき（本人・トレーナーの代理予約） | お客様。本人が予約したときはお店にも |
| 取り消したとき（本人・お店側） | お客様。本人が取り消したときはお店にも |
| 日時を変えたとき（本人・トレーナー） | お客様。本人が変えたときはお店にも |

宛先は、会員はログインしたメールアドレス、ゲストは申込のときに入れたメールアドレスです。
お店への通知には「担当：未定（決めてください）」と入るので、担当の決め忘れにも気づけます。

## 準備（15分ほど）

1. お店の Gmail で Google にログインし、
   https://script.google.com を開いて「**新しいプロジェクト**」を押す
2. 出てきたコードを全部消して、このフォルダの `Code.gs` の中身を**そのまま貼り付ける**
3. 保存（フロッピーのアイコン）
4. 右上の「**デプロイ**」→「**新しいデプロイ**」を押し、次のように選ぶ
   - 種類（歯車のアイコン）… **ウェブアプリ**
   - 次のユーザーとして実行 … **自分**
   - アクセスできるユーザー … **全員**
5. 「デプロイ」を押すと、Google から許可を求められる
   - 「このアプリは Google で確認されていません」と出たら、
     「詳細」→「（プロジェクト名）に移動」→「許可」の順に進む（ご自分で作ったスクリプトなので問題ありません）
   - メールの送信と、外部への通信の許可を求められます
6. 表示された「**ウェブアプリの URL**」（`https://script.google.com/macros/s/……/exec`）を控える
7. アプリの `config.js` の `mailEndpoint` にその URL を入れて、アプリを公開し直す

### 届くか試す

スクリプトエディタで、上の関数リストから `testMail` を選んで実行すると、
お店のアドレスに見本のメールが2通届きます。

### 文面や設定を変えたとき

`Code.gs` を直したら、「**デプロイ**」→「**デプロイを管理**」→ 鉛筆のアイコン →
バージョンを「**新バージョン**」にして「デプロイ」。**URL は変わりません。**

## 安全のための仕組み

- アプリから届いた依頼は、Firebase のログイン（ID トークン）を確かめてから受け付けます
- 送るのは本人の予約か、トレーナーからの依頼だけです
- 宛先は Firestore に記録されたアドレスだけで、依頼する側は指定できません
- 文面は `Code.gs` で決めたものだけです。外から本文を送り込むことはできません

「アクセスできるユーザー：全員」にするのは、会員のみなさんが Google アカウントでログインしていないためです。
URL を知っていても、正しいログインの証明がなければ何も送れません。

## 前日のお知らせについて

前日のお知らせ（「明日のご予約です」）は、この方式ではまだ入れていません。
お客様がアプリを開いていない時間に送るため、別のしくみが必要になります。必要になったら追加します。

## ドメインを使う方式に切り替えるとき

お店のドメインを用意して、差出人をお店のアドレスにしたくなったら、
`mail-worker`（Resend + Cloudflare Workers）に切り替えられます。
`config.js` の `mailEndpoint` を差し替えるだけで、アプリ側の作りは同じです。

# ジム予約・チケット管理アプリ（テンプレート）

パーソナルジム向けの、会員予約とチケット（回数券）管理ができるWebアプリです。
**HTMLファイル1枚＋設定ファイル1枚**で動き、サーバーの契約や毎月の固定費は不要です。

新しいジム様へ導入するときは **`config.js` だけを書き換えます**。
手順は **[SETUP.md](SETUP.md)** をご覧ください。
全体の地図は **[引継ぎ-はじめにお読みください.md](引継ぎ-はじめにお読みください.md)** です。

> 本文中の「first」は、先行して運用している店舗の設定例です。
> 新しいジムでは `config.js` で自由に変えられます。

---

## できること

### 会員（お客様）向け
| 機能 | 内容 |
|---|---|
| 予約 | 日付と時間をタップするだけ。鍛えたい部位のメモも残せます。担当トレーナーは config.js の memberPicksTrainer で切り替え（first は false ＝会員は選ばず、トレーナーが後から決める） |
| マイ予約 | これからの予約の確認・日時変更・取消。締め切り（config.js の cancelHours、first は開始24時間前）を過ぎると、会員は日時変更できず、取り消してもチケットは返却されない |
| グループ | 招待コードで仲間とつながり、仲間の枠に「相乗り」参加できます（`config.js` の `groups: true` を指定した店舗のみ） |
| マイページ | チケット残数、消費・追加の履歴、名前とパスワードの変更 |
| ヒアリングシート | 初回登録時にアンケート形式で入力（あとから編集も可） |

### トレーナー（管理者）向け
| 機能 | 内容 |
|---|---|
| 予約状況 | TimeTree 風の月カレンダー。担当トレーナーごとの色で予約が並び（担当が決まっていない予約は灰色＝「担当未定」）、日をタップで一覧、予約をタップで詳細。担当の割り当て、＋ボタンからの代理予約（チケット不足分はその場で追加）、予約の日時変更（当日も可）、店側都合の取消（チケット返却あり／なし を選択） |
| チケット管理 | 現金を受け取ったら枚数を入力するだけ。履歴は自動で記録されます |
| 会員一覧 | 名前・フリガナで検索。タップでヒアリングシートを閲覧 |
| 会員写真 | 靴・顔・体型のビフォーアフターを記録（任意機能） |
| お休みの設定 | 日付ごとに「1日まとめて」または「時間ごと」に休みを設定（お店全体／担当ごと、メモ付き）。会員の画面では、お店の休みは「お休み」、担当の休みは「予約不可」と表示されます |
| コースの時間割 | コースを使う店舗で、`schedule: true` にしたコース（クラス形式など）の時間を、設定画面で月ごと・曜日ごとに決めます。会員はその時間だけ予約でき、同じ時間はほかのコースでは予約できません。決めていない月は予約できません。トレーナーは、時間割にない時間にも予約を入れられます |
| 設定 | 営業時間、営業日、カレンダーでの自分の色を画面から変更（1枠あたりの人数は `party` か `groups` を使う店舗のみ） |

> **最初に登録したアカウントが自動でトレーナー（管理者）になります。**
> 導入時は、必ずジムのオーナー様が一番に登録してください。

## 構成

```
index.html   … アプリ本体（触りません）
config.js    … 店舗ごとの設定（ここだけ書き換えます）
firestore.rules … データベースの権限設定（Firebaseに貼り付け）
storage.rules   … 写真の権限設定（写真機能を使う場合のみ）
SETUP.md     … 導入手順書
```

技術的には、画面はブラウザだけで動くシングルページアプリ、
データの保存とログインは Firebase（Authentication / Firestore / Storage）を使います。
公開は GitHub Pages でそのまま行えます。

## 費用の目安

| | 料金 |
|---|---|
| 公開（GitHub Pages） | 無料 |
| ログイン・データベース（Firebase Spark） | 無料 |
| 会員写真を使う場合（Firebase Blaze） | 従量課金。無料枠5GB内ならほぼ0円 |

会員数十人〜数百人規模であれば、Firebase の無料枠に収まります。
また Firebase は放置しても自動停止しないため、久しぶりに開いても動きます。

## 動作を試す

`config.js` の Firebase 設定が未入力のあいだは、**デモモードで起動します**。
ダミーデータで全機能を触れるので、ジム様へのご提案時にそのままお見せいただけます
（画面上部に黄色いバーが表示され、会員／トレーナーを切り替えられます）。
「新規登録を体験」を押すと、本番と同じ登録画面（メール・パスワード・お名前・契約書の同意）から始まります。
ログイン画面のデモ用アカウントは `yamamoto@example.com`（会員）と `trainer@example.com`（トレーナー）、パスワードはどちらも `demo1234` です。
